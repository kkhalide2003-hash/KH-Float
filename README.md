# KH Float

تطبيق أندرويد للوصول السريع إلى التطبيقات عبر فقاعات قابلة للسحب وتغيير الحجم والإزالة، بواجهة عربية سوداء مطفأة ولمسات ذهبية.

## التشغيل

```bash
pnpm install
pnpm run dev
```

يمكن تجربة التطبيق عبر Expo Go أو معاينة الهاتف في Replit.

## المزايا

- شاشة ترحيب تحمل عبارة «صنع من قبل Khalid Ouassi».
- تطبيقات جاهزة للفتح مع بحث وتثبيت وإزالة.
- فقاعات قابلة للسحب وتغيير الحجم والحذف.
- إضافة فقاعة أو إزالة جميع الفقاعات دفعة واحدة.
- إعدادات الظهور فوق التطبيقات، الفتح السريع، الوضع المصغّر، والاهتزاز.
- حفظ المساحة والإعدادات محليًا عبر AsyncStorage.

## ملاحظة أندرويد

يحتوي المشروع على تصريح `SYSTEM_ALERT_WINDOW`. أما الفقاعة التي تبقى فوق جميع التطبيقات كخدمة Android حقيقية فتحتاج Native Android foreground/overlay service وبناء Android مخصص، لأن Expo Go يشغّل JavaScript داخل التطبيق فقط.

## بنية المشروع

- `app/(tabs)/index.tsx` — لوحة KH ومساحة الفقاعات.
- `app/(tabs)/apps.tsx` — قائمة التطبيقات والبحث والتثبيت.
- `app/(tabs)/settings.tsx` — إعدادات الوصول والمظهر.
- `context/FloatContext.tsx` — الحالة المحلية والحفظ.
