# KH Floating Hub

تطبيق Android للوصول السريع إلى التطبيقات المفضلة عبر مركز اختصارات قابل للتخصيص.

## إنشاء ملف APK

1. ارفع المشروع إلى GitHub.
2. افتح تبويب **Actions** واختر **Build KH Floating Hub APK**.
3. اضغط **Run workflow** أو ادفع إلى فرع `main`.
4. بعد انتهاء العملية، نزّل `kh-floating-hub-apk` من قسم **Artifacts**.

لإنشاء إصدار ظاهر في صفحة **Releases**، أنشئ tag يبدأ بـ `v` مثل `v1.0.0`. ملف البناء موجود في `.github/workflows/build-apk.yml` في جذر المشروع.

## ملاحظات Android

- التطبيق يطلب صلاحية الظهور فوق التطبيقات لإتاحة تجربة الفقّاعة.
- عند تثبيت APK، افتح إعدادات التطبيق وفعّل **السماح بالظهور فوق التطبيقات** ثم افتح KH مرة أخرى لتشغيل الفقّاعة الأصلية.
- فتح الاختصارات يعتمد على وجود التطبيق المطلوب مثبتًا على الهاتف.
- قد تختلف صلاحية الفقاعات وطريقة منحها بين إصدارات Android والشركات المصنّعة.
